// overview

This project identifies suitable locations for ground-mounted photovoltaic (GMPV) solar parks across the Wetteraukreis and Vogelsbergkreis districts in Hesse, Germany, using a Multi-Criteria Decision Analysis (MCDA) approach with AHP-weighted scoring. The two districts were deliberately chosen for their contrasting terrain — flat versus hilly — to stress-test the methodology under different real-world conditions.

The analysis follows Germany's EEG 2023 §37 "Flächenkulisse" — the legal framework defining where ground-mounted solar parks are eligible for funding, based on proximity to transport corridors, sealed or disadvantaged land, and other criteria.

// methodology

The workflow was split deliberately between two tools, each handling what it does best:

  • ArcGIS Pro — all spatial data preparation: land-use filtering, buffering, and exclusion of unsuitable areas (settlements, water, forests, airports, protected habitats)
  • Python (GeoPandas, Shapely, STRtree) — parcel-level scoring and proximity analysis once the candidate sites were narrowed down
  • Slope and aspect were calculated per-parcel using Zonal Statistics rather than raster erasure, avoiding the jagged sliver geometry that corrupted the first version of this analysis
  • Each candidate site was scored against criteria including settlement buffers, slope tiers, solar irradiation, distance to substations, and land-use type — weighted using an AHP framework

// key learnings

  • Heath terrain was reclassified as a protected habitat and excluded, despite initially appearing favourable for solar siting
  • Small forest copses under 3 hectares were filtered out of the 100m buffer rule, preventing excessive fragmentation of usable farmland
  • National data services (like the BfN WFS) can silently return empty results — falling back to state-level REST services (Hessen geodienste) proved more reliable
  • Mixing GIS and Python mid-workflow created confusion in the first version — keeping spatial prep and analysis cleanly separated made the second version far more maintainable
