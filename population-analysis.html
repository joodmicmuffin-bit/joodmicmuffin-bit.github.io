// overview

This project automates the calculation of each city's share of its federal state's total population across Germany, using an ArcGIS Pro ModelBuilder workflow. Originally developed from a TU Darmstadt coursework exercise, it was independently rebuilt for portfolio presentation using open data.

At its core is a reusable ModelBuilder tool, "CityCalculator", that takes a federal state as input and outputs a point layer of that state's cities, each attributed with its percentage of the state's total population. The model filters municipalities to officially-designated cities ("Stadt"), calculates the population-share field, and names its output dynamically per state.

The analysis was run across four contrasting states — Hessen, Bayern, Bremen, and Nordrhein-Westfalen — to test the model against very different population distributions, with results validated against known city figures. Data preparation involved a spatial join to attribute municipalities with their state, a dissolve to compute per-state totals, and an attribute join using the official municipality key (AGS), resolving common issues like duplicate boundary geometries along the way.

The final deliverable is a multi-map layout: an overview of population per federal state, plus four state-specific maps distinguishing cities above and below a 2% population-share threshold.
