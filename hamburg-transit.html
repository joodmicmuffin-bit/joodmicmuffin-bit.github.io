// overview

This project analyses public transit accessibility along Hamburg's S1 line in the western Altona district, using network-based routing rather than simplified radius buffers to model realistic walking access to transit stops.

For each stop (S-Bahn and bus), I computed a 10-minute walk catchment area using pgr_drivingDistance on a routable street network built from OpenStreetMap data — accounting for actual paths, dead ends, and barriers rather than straight-line distance. Stop locations and service frequency data came from Germany's open GTFS transit feed (DELFI/gtfs.de).

The resulting map reveals a real accessibility pattern: this stretch of the S1 line runs through neighbourhoods with limited transit redundancy — each area typically relies on a single rail line, with local residents' associations (e.g. Bürgerverein Rissen) having raised concerns about accessibility west of Blankenese. The catchment analysis makes that pattern visible and measurable rather than anecdotal.

// notable technical challenge

pgRouting 4.0 removed the legacy pgr_createTopology() function used in most tutorials. I rebuilt the topology-generation step manually using pgr_extractVertices and geometry snapping, adapting to the current API version rather than relying on outdated documentation.

// scope & next steps

This version models static walk-access to stops. A natural extension would incorporate GTFS stop_times.txt for full schedule-aware routing — accounting for actual departure frequency and transfer waits, not just walking distance to the nearest stop.
